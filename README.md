# K线学习

- `kline-atlas.html` K线形态图鉴：42 种常规 K 线 / 图表 / 指标形态，178 个 BTC/ETH 真实案例（含 124 个失败案例），先猜后揭晓的练习。纯静态，无外部依赖。
- `btc-indicators.html` BTC 指标读图台：联动图表（均线 / 布林 / MACD / RSI / KDJ），依赖 cdnjs 上的 ECharts。
- `index.html` 入口页。

数据来源：Binance 现货公开 K 线（BTC/USDT、ETH/USDT，日线 2019 年起，4 小时线 2024 年起），北京时间。学习用途，不构成投资建议。
